# ExtensionMesh organization defaults

This repository contains the public organization profile and shared community
health files for ExtensionMesh repositories.

ExtensionMesh is an open project for practical extension distribution through
independent registries.

## Contents

- [`profile/README.md`](profile/README.md) — public organization profile
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — contribution workflow
- [`GOVERNANCE.md`](GOVERNANCE.md) — lightweight project governance
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) — expected community behavior
- [`SECURITY.md`](SECURITY.md) — security reporting policy
- [`SUPPORT.md`](SUPPORT.md) — support boundaries and channels
- [`.github/ISSUE_TEMPLATE`](.github/ISSUE_TEMPLATE) — shared issue forms
- [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) — shared pull request template

Repository-specific files take precedence over these defaults.
