# Support

ExtensionMesh is an open project maintained on a best-effort basis. Community
support does not include guaranteed response or resolution times.

## Where to ask

- **Reproducible bugs:** use the bug form in the affected repository.
- **Feature proposals:** use the feature request form in the affected
  repository.
- **Implementation questions:** use GitHub Discussions where enabled. Otherwise,
  open a concise issue only if the repository accepts questions.
- **Security vulnerabilities:** follow the private process in
  [SECURITY.md](SECURITY.md).

Include the relevant version or commit, environment, expected behavior, actual
behavior and the smallest reproducible example you can provide.

## Outside project support

The community issue tracker is not a channel for confidential installation
details, customer data, guaranteed consulting or emergency production support.
Organizations may offer separate services, but those services are not official
ExtensionMesh support unless the project explicitly states otherwise.
